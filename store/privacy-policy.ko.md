# AI 웹페이지 번역기 개인정보처리방침

운영자: workingdad365

## 1. 적용 범위

본 방침은 Chrome 확장 프로그램 'AI 웹페이지 번역기'의 데이터 처리에 적용된다. 사용자가 선택한 외부 AI 서비스의 데이터 처리는 해당 서비스의 약관과 개인정보처리방침도 적용받는다.

## 2. 처리하는 정보와 목적

- API 키: 사용자가 선택한 AI 서비스의 인증에 사용한다.
- 모델, 실행 제공자, 말투, 용어집 및 요청 설정: 모델 선택과 번역 품질·속도 조절에 사용한다.
- 웹페이지 콘텐츠: 사용자가 번역을 시작한 페이지의 텍스트와 HTML 조각을 번역에 사용한다. 조각에는 링크 URL 및 HTML 속성이 포함될 수 있다. 페이지 내용에 개인정보나 민감한 정보가 있으면 해당 정보도 번역 요청에 포함될 수 있다.
- 번역 결과와 토큰 사용량: 번역 표시와 속도 측정에 사용한다.

## 3. 외부 전송

번역 요청에는 번역 대상 콘텐츠, 번역 지시, 용어집 및 선택한 모델 관련 설정이 포함된다. API 키는 선택한 서비스에 인증을 위해 전송한다. 모든 구성된 API 엔드포인트는 HTTPS를 사용한다.

| 서비스 | 연결 대상 |
| --- | --- |
| OpenAI | api.openai.com |
| Claude / Anthropic | api.anthropic.com |
| Gemini / Google | generativelanguage.googleapis.com |
| OpenRouter | openrouter.ai 및 라우팅된 하위 모델 제공자 |

모델 목록 조회 시 선택한 서비스에 조회 요청과 필요한 인증 정보가 전송된다. OpenRouter 모델의 실행 제공자 조회도 발생할 수 있다. 속도 측정은 웹페이지 대신 확장에 동봉된 예문으로 번역 요청을 수행한다.

## 4. 로컬 저장 및 삭제

API 키와 설정은 chrome.storage.local에 저장한다. 확장 프로그램은 chrome.storage.sync를 사용한 설정 동기화를 구현하지 않는다. API 키를 별도로 암호화해 보관하는 기능은 없다.

번역 처리를 위한 페이지 상태와 캐시는 실행 중 메모리에 유지한다. 사용자는 설정에서 저장값을 변경하거나, 확장 프로그램을 제거하여 해당 확장의 로컬 저장 데이터를 삭제할 수 있다. 이미 외부 AI 서비스로 전송된 데이터의 보관·삭제는 각 서비스의 정책과 계정 설정에 따른다.

## 5. 디버그 로그

사용자가 디버그 모드를 켜면 브라우저 개발자 도구 콘솔에 요청 대상 텍스트, 오류와 응답 일부 등이 기록될 수 있다. 디버그 로그에는 페이지 콘텐츠가 포함될 수 있으므로 외부 공유 시 주의가 필요하다. 별도의 분석·광고 추적 SDK나 자동 로그 수집 서버 전송 기능은 확장 코드에 포함되어 있지 않다.

## 6. 데이터 사용 범위

확장은 OpenAI, Anthropic, Google, OpenRouter API에 연결한다. 별도의 개발자 개인 프록시 서버를 기본 연결 대상으로 사용하지 않는다. 사용자 데이터는 번역과 관련 설정·기능 제공을 위해서만 처리하며, 광고 또는 판매, 신용도 판단이나 대출 목적으로 사용하지 않는다. 외부 전송은 사용자가 선택한 번역 서비스에 기능 제공을 위해 이루어진다.
