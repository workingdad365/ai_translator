# Chrome 웹 스토어 등록 자료

## 기본 정보

- 이름: AI 페이지 번역기
- 버전: 1.0.13
- 언어: 한국어
- 카테고리 제안: 생산성 / 도구(대시보드의 실제 선택지에 맞춰 선택)
- 홈페이지: https://github.com/workingdad365/ai_translator
- 지원 페이지: https://github.com/workingdad365/ai_translator/issues
- 공개 범위 및 지원 이메일: 게시자 확인 필요

## 상세 설명

원하는 AI 모델로 웹페이지를 한국어로 번역한다.

AI 페이지 번역기는 사용자가 직접 선택한 AI 서비스와 API 키를 이용해 현재 보고 있는 웹페이지를 한국어로 번역하는 확장 프로그램이다. 번역 버튼을 누르면 화면에 보이는 내용부터 번역하고, 스크롤로 나타나는 내용과 동적으로 추가되는 게시물도 이어서 처리한다.

주요 기능
- OpenAI, Claude, Gemini, OpenRouter 지원
- 서비스별 API 키와 모델 설정 저장
- 모델 목록 조회 및 OpenRouter 실행 제공자 선택
- 반말 기사체, 존댓말, 화자별 말투를 유지하는 캐주얼체 선택
- 용어집으로 고유명사와 전문 용어의 번역 지정
- 링크와 인라인 HTML 구조를 보존하는 번역
- 배치 크기, 동시 요청 수, 타임아웃과 추론 강도 조절
- 동봉 예문을 이용한 번역 속도 측정
- 번역 중지 및 진행 상태 표시

사용 방법
1. 확장 프로그램의 설정에서 AI 서비스를 선택한다.
2. 해당 서비스의 API 키와 사용할 모델을 입력한다.
3. 번역할 웹페이지에서 확장 아이콘을 누르고 '이 페이지 번역'을 선택한다.
4. 페이지를 스크롤하면 새로 보이는 내용도 번역한다.

이용 안내
- 별도의 AI 서비스 계정과 유효한 API 키가 필요하다. API 이용 요금과 사용 제한은 선택한 서비스의 정책을 따른다.
- 번역 대상 텍스트와 HTML 조각, 용어집 등 번역 지시가 선택한 AI 서비스로 전송된다. OpenRouter는 요청을 하위 모델 제공자에게 전달할 수 있다.
- API 키와 설정은 브라우저의 확장 프로그램 로컬 저장소에 저장된다.
- 이미지 속 글자, PDF 및 Chrome 내부 페이지 번역은 지원 대상이 아니다. 일부 사이트에서는 페이지 구조에 따라 번역이 제한될 수 있다.
- AI 번역에는 오류가 있을 수 있다.

## 단일 목적

사용자가 요청한 웹페이지의 텍스트를 선택한 AI API로 한국어 번역하고, 해당 페이지 안에 번역 결과를 표시한다.

## 권한 사용 사유

### storage

AI 서비스별 API 키와 모델, 말투, 용어집, 번역 배치 크기 및 기타 사용자 설정을 chrome.storage.local에 저장하고 다음 사용 시 복원한다.

### activeTab

사용자가 확장 팝업에서 번역 시작 또는 중지를 요청할 때 현재 활성 탭을 확인하고 해당 탭의 콘텐츠 스크립트에 명령을 전달한다.

### http://*/* 및 https://*/* 콘텐츠 스크립트 접근

사용자가 선택한 다양한 웹사이트에서 번역 대상 텍스트를 읽고 번역 결과를 표시한다. 스크롤과 동적 콘텐츠 추가를 감지해 사용자가 시작한 번역을 이어간다. 페이지에 스크립트가 로드되어도 사용자가 번역을 시작하기 전에는 번역 요청을 전송하지 않는다.

### AI API 호스트 접근

선택한 AI 서비스에 모델 조회 또는 번역 요청을 전송한다. API 접근 권한은 api.openai.com, api.anthropic.com, generativelanguage.googleapis.com, openrouter.ai 네 호스트에만 선언한다.

## 데이터 공개 항목 초안

- 웹사이트 콘텐츠: 번역 대상 텍스트와 HTML 조각을 외부 AI API로 전송함.
- 인증 정보: 사용자가 입력한 API 키를 로컬에 저장하고 선택한 서비스에 인증용으로 전송함.
- 페이지의 링크 URL과 속성, 용어집 내용도 요청에 포함될 수 있음.
- 검색 기록 전체를 조회하거나 별도의 광고·행동 추적 데이터를 전송하는 코드는 없음.
- 페이지 내용 자체에 개인정보, 개인 통신 또는 민감한 정보가 포함될 수 있으므로 '어떤 사용자 데이터도 처리하지 않음'으로 신고하지 않음.
- 실제 대시보드의 정의에 따라 데이터 유형을 검토하고, 최종 공개 배포본의 데이터 처리 방식에 맞춰 확인함.
- 원격 코드: 원격 JavaScript 또는 WebAssembly를 받아 실행하는 기능이 없음. 외부 AI API 응답은 번역 데이터로 처리함.

## 심사용 테스트 안내

1. 확장 프로그램을 설치하고 일반 웹페이지(예: https://example.com)를 연다.
2. 확장 아이콘을 클릭하고 설정에서 심사용으로 제공된 서비스, API 키 및 모델을 입력한다.
3. '이 페이지 번역'을 클릭한다. 영어 제목과 문단이 한국어로 변경되는지 확인한다.
4. 긴 웹페이지에서 스크롤해 추가 영역이 번역되는지 확인한다.
5. 말투와 용어집을 변경한 뒤 웹페이지를 새로고침하고 다시 번역한다.
6. '속도 측정'을 클릭해 동봉 예문의 번역 결과와 토큰 사용량 기반 측정 결과를 확인한다.

실제 심사용 서비스·모델·자격증명은 준비 후 비공개 심사 입력란에만 제공한다. 공개 저장소, ZIP, 스토어 소개에는 포함하지 않는다. 개인 운영 키 대신 사용 범위와 예산을 제한한 심사용 키를 사용한다.

## 제출 전 남은 항목

- 최종 배포본에 맞춰 개인정보처리방침과 운영자 연락처 확정
- 개인정보처리방침 공개 URL 생성 및 접근 확인
- 최신 UI 스크린샷 확보 또는 기존 설정 화면의 등록 이미지 검토
- 심사용 API 접근 수단 마련
- 공개 범위와 대상 국가 확정
- 대시보드에서 실제 데이터 공개 항목 검토 후 심사 제출
